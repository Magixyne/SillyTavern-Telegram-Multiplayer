# 2026-07-30

## 修复 SillyTavern Extension 合规性

参考官方文档 [Writing-Extensions.md](https://raw.githubusercontent.com/SillyTavern/SillyTavern-Docs/main/For_Contributors/Writing-Extensions.md)，对扩展进行了以下修复：

### manifest.json
- 移除了废弃的 `requires` 和 `optional` 字段（这两者是旧 Extras 系统的残留）
- 添加了 `hooks.activate` 生命周期钩子，指向 `onActivate`
- 添加了 `dependencies: []` 字段
- 更新了 `homePage` 指向当前 fork 仓库

### index.js
- **初始化方式**：用 `exports.onActivate()` 生命周期钩子替换了 `jQuery(async () => {})` 模式
- **API 调用**：对 `eventSource`、`event_types`、`extensionSettings`、`saveSettingsDebounced`、`deleteLastMessage`、`selectCharacterById`、`openCharacterChat`、`Generate(generate)` 使用 `SillyTavern.getContext()` 获取，遵循最佳实践
- **直接 import**：仅保留 `getPastCharacterChats`、`sendMessageAsUser`、`doNewChat`、`setExternalAbortController` 四个未在 getContext() 中暴露的函数
- **设置初始化**：`DEFAULT_SETTINGS` 使用 `Object.freeze()` 防止意外修改
- **设置合并**：`getSettings()` 使用 `for...in` 确保新增默认键不丢失
- **自动连接**：改为在 `APP_READY` 事件后触发，避免阻塞应用加载
- **settings.html 加载**：路径改为 `/scripts/extensions/${EXTENSION_FOLDER}/settings.html`

### 关键发现
- `getContext()` 暴露了大量 API（详见 st-context.js 源码），包括 `eventSource`、`event_types`、`generate`、`selectCharacterById`、`openCharacterChat`、`deleteLastMessage`、`saveSettingsDebounced` 等
- SillyTavern 不鼓励直接从 `script.js` 导入，因为内部结构可能随时变化
- `renderExtensionTemplateAsync()` 是推荐的模板加载方式，但需要知道精确的安装文件夹名
