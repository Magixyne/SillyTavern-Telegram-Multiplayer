# 2026-07-31

## 添加 Multiplayer 支持

根据用户需求，为扩展添加了完整的 Multiplayer 群组支持：

### settings.html
- 添加了 Multiplayer 开关复选框
- 添加了用户消息前缀格式下拉选择（支持 `<用户>: `、`用户: `、`[用户]: `、`*用户* ` 等格式）
- 添加了默认游戏模式选择（即时模式/缓冲模式）
- 包含使用说明

### index.js
- 添加了 `multiplayerEnabled`、`userPrefix`、`defaultMode` 三个默认设置项
- 添加了 `applyUserPrefix()` 工具函数，根据设置的用户名前缀格式化消息
- 在处理用户消息时，如果启用了 Multiplayer 模式，自动添加用户名前缀
- 设置界面事件绑定更新

### server/server.js
- 修改了 `user_message` 消息 payload，添加了 `username` 字段传递 Telegram 用户名
- 日志输出也添加了用户名显示

### 使用方式
1. 在 SillyTavern 扩展设置中启用 "Multiplayer 模式"
2. 选择用户消息前缀格式
3. 在 Telegram 群组中发送消息时，AI 将看到带有用户名前缀的消息，方便区分不同玩家
