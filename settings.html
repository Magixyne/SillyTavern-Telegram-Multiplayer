💡 使用提示：
· 内置 Server 模式（推荐）：装好 server 插件后，这里填 Token → 保存 → 启动 → 连接，URL 留空自动探测端口。
· 或独立部署 server/ 目录，Bridge URL 填 ws://服务器IP:2333。
· 即时模式 + 合并窗口：玩家连续输入时 AI 不会逐条回复，攒一波再回。
· 缓冲模式：适合多人轮流行动的 RPG 场景。
· 私聊消息在酒馆中会显示 Telegram 用户名作为来源。
